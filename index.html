ランクマップ ― Sから順に制覇しよう

ランクは入試での出やすさ・重要度順。タップすると、そのランクだけに絞って学習できます。まずはSを全部「覚えた」にするのが目標。各ランクの詳しい説明は、下の「このアプリについて」にあります。

遊び方・レベルアップのしくみ

  • カードで「覚えた！」 → ＋10 XP。クイズ・聞き取りクイズ正解 → ＋20 XP、3連続正解ごとにボーナス＋10 XP。
  • 聞き取りクイズは、音声で流れる英単語を聞いて、意味を4択から選ぶモード。聞き取るのは単語だけに絞っていて、長文の聞き取り教材は入っていない。まちがえた単語は通常のクイズと同じく苦手リストに入る。
  • XPがたまるとレベルアップ。レベルが上がると称号も上がっていく。
  • まちがえた単語は「苦手」に自動で入り、「苦手だけ」フィルターで集中復習できる。復習で正解すると苦手から外れる。
  • 進み方は S → A → B → C → D → E の順がおすすめ。SとAを制覇すれば入試長文の土台は完成。D・Eの熟語と発展語彙が、難関校で差をつける。
  • 熟語カードは英語のフレーズがそのまま出る。不規則動詞カードは「原形 → 過去形 → 過去分詞」の順で表示されるので、声に出して覚えよう。

このアプリについて ― 英単語専門の理由

他の英語アプリと違い、このアプリは機能を英単語の暗記だけに絞っています。文法ドリルも、長文読解もありません。リスニングも、英単語を聞いて意味を選ぶ「聞き取りクイズ」だけに絞っています。その代わり、高校受験で問われる単語を約3,333語収録し、1語ごとに入試ランク（S〜E）を付けました。中2の今のうちに単語を制覇しておくことが、3年での長文・英作文の伸びを決めます。

ランク（S〜E）の詳しい説明

ランクは入試での出やすさ・重要度と難しさ順。S＝超頻出、A＝頻出、B＝標準、C＝発展が基本語彙。その上に、入試で問われる熟語・連語を集めた D＝難関・熟語 と、不規則動詞の活用と難関・上位校の発展語彙を集めた E＝最難関 を上乗せしています。各ランクの収録数は上のランクマップに表示されます。進み方は S → A → B → C → D → E の順がおすすめ。SとAを制覇すれば入試長文の土台は完成し、D・Eの熟語と発展語彙が難関校で差をつけます。

TANGOは英単語の暗記だけに特化した、単語専門アプリです。収録語は中学校の学習指導要領の語彙と、公立・私立高校入試の頻出語・熟語をもとに構成しています。
